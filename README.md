# ⚽ 부산시청 축구회 - FIFA 스타일 포메이션 매니저

시도별 공무원 전국 축구대회 승리 대비 선수 분석 및 전술 라인업 시스템

---

## 🌟 주요 기능
1. **FIFA 6대 육각형 능력치 시스템**
   - **PAC (스피드/주력)**, **SHO (슈팅/결정력)**, **PAS (패스/시야)**, **DRI (드리블/탈압박)**, **DEF (수비/차단)**, **PHY (피지컬/스태미너)**
   - Chart.js 기반 육각형 레이더 차트 실시간 렌더링
   - 선수별 포지션 맞춤 종합 평점(OVR) 자동 계산 및 플레이스타일 태그 부여
2. **FIFA Ultimate Team 골드 카드 뷰**
   - 선수 등번호, 이름, 소속 부서(과), 주발, 나이 및 6대 스탯 카드 시각화
3. **인터랙티브 전술 포메이션 구장 보드**
   - 프리셋 포메이션: `4-3-3`, `4-4-2`, `4-2-3-1`, `3-5-2`, `5-3-2`
   - 필드 위 선수 클릭/드래그 앤 드롭 스왑(교체) 배치
   - 선발 11명 + 교체 후보(벤치) 실시간 관리
   - 팀 종합 전력 대시보드 (팀 OVR, 평균 스피드, 평균 체력 등 실시간 반영)
4. **대회 브리핑용 라인업 이미지(PNG) 원클릭 저장**
   - 경기 전 감독 브리핑 및 단체 대화방 공유용 고해상도 라인업 이미지 자동 생성
5. **엑셀(Excel) 명단 연동**
   - 전체 선수단 명단 엑셀 다운로드 및 일괄 업로드(가져오기) 지원
6. **독립 실행 파일 (EXE)**
   - `dist/부산시청_축구회_포메이션_매니저.exe` 더블클릭만으로 즉시 구동

---

## 🚀 실행 방법

### 1. EXE 실행 (가장 간편한 방법)
* `dist/` 폴더 안의 **`부산시청_축구회_포메이션_매니저.exe`**를 더블 클릭하여 실행합니다.

### 2. 소스코드에서 실행 (개발자용)
```bash
python main.py
```
